# Day-1-Bus_Simulator_Hafsah-Mulyani

Deskripsi : Repository adalah folder digital pintar buat menyimpan semua file proyek codingan yang kita buat.

Tujuan : Menjadi pusat kontrol dan keamanan seluruh aset proyek codingan yang kita buat.

Prompt Engineering merupakan cara merancang intruksi agar AI memberikan jawaban yang tepat, relevan, dan layak untuk digunakan. Arti Prompt sendiri adalah instruksi atau masukan yang Anda berikan
kepada model untuk mendapatkan hasil tertentu.

Kelebihan dari prompt engineering
- Meningkatnya performa AI model
- Mengurangi respon yang offensive
- Meningkatkan kontrol dan predictability
- Memberikan pengalaman lebih baik

Git/Github

Git : Version Control System yang digunakan untuk melacak dan mengelola perubahan kode secara lokal

Github : Tempat menyimpan repository Git secara online

Command Git

- git init : Menambah file reopsitory

- git add : Memindah file ke staging 

- git comit -m 'message' : Menyimpan file repository


Note : AI tidak bisa menyimpan histori kita, banyak hal yang terjadi di belakang AI tersebut. Ketika kita tidak memberi batasan, AI tidak akan tahu apa yang kita mau
